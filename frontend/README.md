# Border Screening Platform — Officer Dashboard (Frontend)

Operational officer web dashboard for real-time document screening inspection, evidence examination, and human-in-the-loop decision recording.

## Architecture Boundaries
- **Runtime:** Node.js 20+ / Next.js (App Router)
- **Language:** TypeScript (Strict Mode)
- **Styling:** Tailwind CSS + Minimal Design Tokens (`--bg`, `--surface`, `--line`, `--text`)
- **End-to-End Testing:** Playwright
- **Design Philosophy:**
  - Fast, high-density, professional operational workflow.
  - Zero decorative AI clutter, glassmorphism, or unexplained 0-100 risk gauges.
  - Clear, auditable evidence hierarchy (validations, mismatches, anomaly regions).
